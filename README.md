# Sever Store

Учебный проект: веб-витрина онлайн-магазина. Реализованы каталог, поиск, категории, корзина, оформление заказа, регистрация и авторизация.

## Запуск

1. Дважды щёлкните start_server.bat.
2. Дождитесь автоматической установки и открытия браузера.

При первом запуске файл автоматически проверит Python, при необходимости попробует установить его через Windows Package Manager, создаст локальное окружение, скачает библиотеки, запустит сервер и откроет сайт. Node.js для проверки готового проекта не требуется.

Сайт: http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs

Тестовый администратор: admin@sever.local, пароль admin123.
